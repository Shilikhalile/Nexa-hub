# Nexa Voice — Design Direction

## Chosen direction
**Signal Console** — an intimate, dark voice command console that feels like a calm cockpit for the user's device.

## Design movement
Editorial product design meets sci-fi utility: precise grids, thin borders, cyan signal accents, and restrained motion.

## Core principles
- Voice is the primary action, not a hidden feature.
- Every command has visible feedback: Listening → Understanding → Done.
- Keep the interface calm, legible, and honest about browser/device limits.
- Make mixed-language Tunisian, Arabic, French, and English feel welcome.

## Color philosophy
Use Nexa-hub's existing deep navy foundation. Electric cyan is the active signal and success state; violet is reserved for secondary system data. Avoid loud gradients and visual noise.

## Layout paradigm
Desktop: two-column command console with a dominant voice module and a compact device-status rail. Mobile: single-column flow with the voice action first.

## Signature elements
- A large circular voice button with a live waveform ring.
- Status pill that changes from Ready to Listening to Understanding to Complete.
- Recent command rows with intent labels.
- Device health cards for battery, storage, RAM, and temperature.

## Interaction philosophy
Immediate feedback, forgiving command phrasing, suggestions when confidence is low, and confirmation language for actions that may be sensitive. This prototype keeps actions local and safe.

## Animation
Subtle pulse while listening, small status transitions, and short reveal motion. Respect prefers-reduced-motion.

## Typography system
Manrope for headings and interface labels; DM Sans for supporting copy and command transcripts.

## Brand essence
A Tunisian-first personal assistant that feels capable without pretending it can bypass Android permissions.

## Brand voice
Clear, warm, concise, and lightly Tunisian: “حاضر، حلّيتلك YouTube.” / “ما فهمتش الأمر توا، جرّب صياغة أخرى.”

## Wordmark / logo
Reuse the existing Nexa-hub N mark and wordmark. The Voice product is a focused mode within the Nexa family.

## Signature brand color
Electric cyan `#6de7ec` on deep navy `#07111f`.
